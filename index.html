Arquitectura Real del Proyecto

Qué módulos funcionan hoy y qué se completa para mayo de 2027

Sin promesas vacías: estas son las piezas técnicas reales que componen Evaluario.

OPERATIVO · MEMORIAS TÉCNICAS PDF

Corrección de prácticas de Redes y Sistemas

Extrae texto e imágenes de cada página del PDF entregado por el alumno y verifica cada requisito técnico con modelos de visión ejecutados en local.

  • ▸ Soporta reglas personalizadas por número de lista del alumno (ej. subred 192.168.{N}.0/24).
  • ▸ Genera la lista de comprobaciones automáticamente a partir del PDF de tu enunciado.
  • ▸ Enlaza cada criterio directamente con la página y captura donde se encontró la evidencia.
OPERATIVO · SANDBOX DOCKER MYSQL 8.4

Evaluador de Bases de Datos SQL con casos límite

Ejecuta los scripts .sql de los alumnos dentro de un contenedor Docker con MySQL 8.4 aislado sin red (network_mode: none) y compara el resultado real.

  • ▸ Doble juego de pruebas: verifica con los datos del enunciado y con datos ocultos de casos límite.
  • ▸ Agrupa en clústeres las consultas que devuelven el mismo resultado parcial para calificarlas juntas.
  • ▸ Evalúa creación de esquemas (DDL), consultas (SELECT) y operaciones de modificación (DML).
OPERATIVO · ANÁLISIS FORENSE DE EVIDENCIAS

Detector privado de capturas compartidas

Cruza los identificadores técnicos extraídos de las capturas de toda la clase que no deberían coincidir entre dos máquinas virtuales distintas.

  • ▸ Detecta direcciones MAC idénticas, UUIDs de disco o exactamente el mismo segundo en el reloj.
  • ▸ Descarta automáticamente valores comunes del taller (como la IP 10.0.2.15 de red NAT).
  • ▸ Nunca penaliza la nota por su cuenta: muestra una alerta discreta solo para el docente.

Respuestas claras sobre privacidad y funcionamiento técnico

Porque todo el procesamiento ocurre en local: tanto el análisis visual de las memorias en PDF (mediante Ollama en tu equipo o servidor del centro) como la ejecución de consultas SQL (en un contenedor Docker con MySQL 8.4 sin red) funcionan sin enviar ningún documento ni nombre de alumno a servidores de terceros.
Cada entrega SQL se ejecuta en un contenedor efímero con la red deshabilitada (network_mode: none), límite estricto de memoria RAM, cuota de CPU y tiempo máximo de ejecución. Al terminar la comprobación, el contenedor se destruye limpiamente.

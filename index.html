FICHA 01 · REDES Y SISTEMAS

Memorias en PDF llenas de capturas de terminal

Aunque el alumno pegue capturas oscuras y diminutas de Ubuntu o Windows Server, el lector amplía y mejora el contraste antes de leer cada línea.

  • ▸ Comprueba que cada alumno use su propio número en la IP (192.168.XX.1).
  • ▸ Propone la lista de puntos directamente leyendo el PDF o Word de tu enunciado.
  • ▸ Te lleva con un clic a la página exacta donde está cada captura.
FICHA 02 · BASES DE DATOS

Prácticas de SQL probadas con datos reales y casos trampa

No mira el código por encima: ejecuta las tablas y consultas de cada alumno en un entorno aislado y compara los resultados con tu solución.

  • ▸ Pilla las consultas mal hechas que acertaban de casualidad con pocos datos.
  • ▸ Agrupa a los alumnos que tienen el mismo fallo para que decidas el criterio una sola vez.
  • ▸ Evalúa creación de tablas (DDL), consultas (SELECT) y modificaciones (DML).
FICHA 03 · DETECTOR DE COPIAS

Aviso discreto cuando dos memorias comparten máquina

En vez de comparar fotos que siempre se parecen, busca en las capturas datos que nunca coinciden por azar entre dos ordenadores distintos.

  • ▸ Detecta direcciones MAC idénticas o la misma hora exacta hasta el segundo.
  • ▸ Ignora lo que es normal que coincida en toda la clase (como la red NAT de VirtualBox).
  • ▸ Muestra un aviso solo para ti con un botón para comparar ambas entregas cara a cara.
